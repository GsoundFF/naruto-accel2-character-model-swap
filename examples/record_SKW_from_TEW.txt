一、任务
--------------------------------------------------------------------------------
让 小樱(Sakura, SKW) 显示 天天(Tenten, TEW) 的外观（身体+贴图+奥义/选人模型），
但保留小樱的动作/招式/骨架。方法完全复用《静音换井野》《天天换小樱》的
"外科手术+原位补丁"方法论（见 _成功流程记录_静音换井野_MOD4.txt 与
_成功流程记录_天天换小樱_MOD.txt）。

二、角色代码确认（与 SKR/TEN 的关系）
--------------------------------------------------------------------------------
同一角色在 /PL/ 下往往有多个代码（多为不同服装/版本）。经 _id_chars.py 渲染
body 脸部贴图肉眼确认：
  小樱 = SKR、SKW、SKN（多套服装）；天天 = TEN、TEW。
  本任务方向：小樱 = SKW（基底，保留动作），外观 ← 天天 TEW。
  （注：另一套已完成的 _成功流程记录_天天换小樱 _MOD 用的是 SKR←TEN；
    本记录是平行的一套 SKW←TEW，产出不同代码变体。）
辅助脚本：_id_chars.py、_colorhist.py、_analyze_skr_ten_variants.py。

三、各文件结构（关键，脚本内注释已详述）
--------------------------------------------------------------------------------
【战斗文件 /PL/2SKWBOD1.CCS ← /PL/2TEWBOD1.CCS】
  SKW 骨架 32 骨：0-13 标准 + 14-17 马尾辫 + 18-23 l/r 肩臂手指 + 24-27
    r upperarm..r finger0（对照 SKR 30 骨带 tail，SKW 无 tail 但插入了马尾）
    + 28-31 cloth/body。
  TEW 骨架 25 骨（与井野/天天常规布局相同，0-23 标准 + 24 body）。
  body 名字编号：SKW body=3696 / MAT=3697 / TEX=3698(clut3726) / CLT 3726..3728(3个)
                 TEW body=4939 / MAT=4940 / TEX=4941(clut5025) / CLT 5025..5027(3个)
  骨架 0-13 & 18-23 同名 → 其余（14-17、24-27、28-31）按名字映射，lookup 重写。
  换：body 数据（名字编号 4939→3696、lookup 按名字表重映射、子网格材质
    4940→3697）；贴图内容（名 4941→3698、clut 指针 5025→3726）；调色板内容
    （5025/5026/5027 → 3726/3727/3728）。TEW body 数据 51936B（rec=+1200）。
  新 lookup：[4,11,18,3,20,19,23,25,24,12,13,8,5,6,7,21,22,26,27,9,10]
  （TEW lookup 21 项，max < 32 骨架位置）
【奥义变体 /PL/MODEL/2*BOD1】
  SKW MODEL：1 个 body(idx98/MAT99/tex100/cluts102-104)。
  TEW MODEL：3 个等同 body(00t0 idx98、02t0 199、05t0 300)，取 00t0。
  body lookup 按 TEW(25骨)→SKW(32骨) 名字表映射重写；body 编号天然对齐
  (98/99/100)、clut 318→102。TEW 贴图 clut 318 → SKW 102，调色板
  318/319/320 → 102/103/104。
【1P 高模 /PL/1SKWBOD1.CCS ← /PL/1TEWBOD1.CCS】（奥义特写/选人画面）
  SKW 1P = 66 骨；TEW 1P = 49 骨。两者 0-11 相同，其余按名字映射（程序从
    clump boneIndices 自动建表，映射 TEW pos → SKW pos，fallback=65）。
  body 编号对齐：body189/MAT190/TEX191(clut193)/CLT193/194/195；眼/嘴贴图
    clut 196/197。
  换：body 数据(lookup 按名字映射重写)、body TEX/CLUT、eye/mou 的 TEX+CLUT
    （注意 index 不同：TEW eye idx117→SKW 122、mou idx124→SKW 129；clut
    201/202→196/197）、3 个刚性面部件(eye1/eye2/mou1 几何移植，名字
    idx/parent/material 保留 SKW 原件——否则引擎崩，见井野 1P 教训)。
  TEW 1P body 96408B(rec=+2220)；SKW 原 114440B。

六、测试方法（用户）
--------------------------------------------------------------------------------
模拟器打开 MOD_Sakura_Tenten_full.iso → 选 小樱(SKW 那套服装) → 进战斗看外观；
开奥义看特写；看选人画面。预期：小樱显示天天的身体/脸/发型，招式仍是小樱的。
若战斗/奥义崩 = 还有结构问题；若某个画面仍是原小樱 = 对应变体没生效。

七、踩坑/要点
--------------------------------------------------------------------------------
0) ★奥义层层递进（同井野 MOD4/MOD5/MOD6 教训，已验证）：
   - 战斗模型 /PL/2SKWBOD1.CCS 先单独换、模拟器验证战斗外观正常（battle 版）；
   - 奥义演出用的不是 MODEL 变体：先换 MODEL 版往往**无效**；
   - 奥义真正生效的是 /PL/1SKWBOD1.CCS（1P 高模，选人+奥义共用）；
   - 因此最终完整版 = 已验证战斗版基底 + MODEL + 1P 两处奥义补丁。
1) SKW 有马尾(14-17)、TEW 无 tail；战斗/MODEL/1P 骨架位置不是天然恒等对齐，
   必须用"按骨架名字"映射（从 clump boneIndices 枚举序号取位置号，
   不能用名字表编号，否则写出一堆上千索引 → 崩）。与 skr_ten 1P 教训一致。
2) 1P 眼部刚性件(eye1/eye2/mou1) parent[28] 引用配套 "_0" 块、material[32]
   引用本件材质：移植几何时保留目标(SKW)原件值，只换名字编号+几何。
3) 1P eye/mou 贴图 index 与 clut 均与 SKW 不同，必须逐项改（eye 117→122、
   mou 124→129；clut 201/202→196/197），body clut 193/194/195 ← TEW 198..200。
4) 调色板(CLUT)数量两角色不等时（本例战斗 3vs3、MODEL 4vs3、1P 3vs5）用已有
   tint 调色板内容复用；默认外观只走第 1 个 CLUT，不影响。
5) 本记录与 _成功流程记录_天天换小樱 _MOD 是平行两套（SKR←TEN 与 SKW←TEW），
   都采用相同方法论；产物分两个 ISO。
