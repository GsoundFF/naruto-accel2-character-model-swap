一、任务
--------------------------------------------------------------------------------
让 小樱(Sakura, SKW) 显示 静音(Shizune, SZW) 的外观（身体+贴图+奥义/选人模型），
但保留小樱的动作/招式/骨架。方法完全复用《静音换井野》《天天换小樱》的
"外科手术+原位补丁"方法论（见 _成功流程记录_静音换井野_MOD4.txt 等）。

二、角色代码确认
--------------------------------------------------------------------------------
本任务源=静音 SZW（与井野那套的源相同），目标=小樱 SKW（与前一篇
天天换小樱_SKW_TEW 的目标相同）。
方向：小樱 = SKW（保留动作），外观 ← 静音 SZW。
分析脚本：_analyze_skw_szw.py（三套 battle/MODEL/1P 骨架+索引+clut 全量dump）。

三、本次的关键简化（与 TEW 那套相比）
--------------------------------------------------------------------------------
SZW 与 SKW 的索引在 MODEL 与 1P 里几乎完全对齐，只差骨架，非常清爽：

【战斗 2SKW←2SZW】SKW 32骨 / SZW 34骨（SZW 多 cloth1/cloth2/body，实际
  不参与 body 蒙皮）。SZW body lookup 全部 ≤ 30，与 SKW 0-30 同名位置一致
  → lookup 恒等映射（defensive pmap 得到恒等）。
  body：SZW idx4671 → SKW 3696；子网格材质 4672 → 3697。
  TEX_2szwbody 4673(clut4752) → 名3698 + clut 3726。
  CLUT 4752/4753/4754 → 3726/3727/3728。
  SZW body 55784B（SKW 原 65912B）。
【MODEL /PL/MODEL/2SKWBOD1←2SZWBOD1】两边 idx98/mat99/tex100(clut102)、
  cluts 102/103/104 完全一致 → 只需复制 body 几何 + 贴图 + 调色板内容，
  lookup 按 pmap（防御性，结果恒等）。SZW MODEL body 52012B。
【1P /PL/1SKWBOD1←1SZWBOD1】SKW 66骨 / SZW 64骨。
  body idx189/mat190、TEX 191(clut193)、cluts 193/194/195、eye tex 122(196)、
  mou tex 129(197) 全部一致。
  只做：lookup 按名字映射（SZW 64→SKW 66，pmap fallback=65）；
  眼嘴件(eye1/eye2/mou1) 移植几何，parent/material/名字编号保留 SKW 原件；
  body/eye/mou 贴图与调色板整段复制（索引已对齐）。
  SZW 1P body 96408→实际 84168B（SKW 原 124600B）。
  （1P 是奥义+选人画面的真身，同井野 MOD6 结论。）

四、实施（脚本，均在 ROOT 下）
--------------------------------------------------------------------------------
分析：  _analyze_skw_szw.py
手术：  _swap_battle_skw_szw.py（战斗版）
        _swap_model_skw_szw.py（MODEL 版）
        _swap_1p_skw_szw.py（1P 版，按名字映射 + 眼/嘴件）
打包：  _patch_skw_szw_mod.py（原位补丁，三处 → MOD_Sakura_Shizune_full.iso）
验证：  每步均 readCCS 重解析：块数/顺序一致、meshCount/lookup/材质/贴图
        clut 全部正确、walk 到 EOF；新 gz ≤ 原文件长度；全盘比对三处差异。

五、基底选择的重要说明
--------------------------------------------------------------------------------
本次不能复用已验证战斗版 MOD_Sakura_Tenten_battle.iso 当基底，因为那盘的
/PL/2SKWBOD1.CCS 已被换成 TEW(天天)来源的战斗补丁，与本任务的 SZW 源冲突。
→ 本任务基底 = 原版盘，一次性原位打三处 SZW 补丁。

七、测试方法（用户）
--------------------------------------------------------------------------------
模拟器打开 MOD_Sakura_Shizune_full.iso → 选 小樱(SKW 那套服装) → 进战斗看外观；
开奥义看特写；看选人画面。预期：小樱显示静音的身体/脸（白衣/马尾注意是静音
的），招式仍是小樱的。若战斗/奥义崩 = 还有结构问题；若某个画面仍是原小樱 =
对应变体没生效（优先怀疑 1P 文件）。

八、踩坑/要点
--------------------------------------------------------------------------------
1) SZW 34骨（底+马尾+衣摆 cloth1/cloth2/body）、SKW 32骨（底+马尾+tail1/2/body）。
   战斗/MODEL 骨架 0-30 同名恒等，lookup 无需映射（防御 pmap 恒等）；
   1P 骨架 64 vs 66 需按名字映射（clump boneIndices 枚举序号取位置号）。
2) 1P 眼嘴刚性件(eye1/eye2/mou1) parent[28]/material[32]/名字idx 保留 SKW
   原件，只移植几何——否则引擎崩（与前两套 1P 教训一致）。
3) 本任务 SZW 源与"静音换井野"的源完全相同(2SZW/1SZW/MODEL2SZW)，但目标骨架
   布局不同，仍需各自按名字确认映射，不可直接套用井野的 lookup 表。
4) 调色板数量：本任务三处两两都是 3v3 对齐，无需复用 tint 补位（比 TEW 简单）。
